# stable-metaswarm

Оркестратор CLI-агентов от разных вендоров. Ведёт задачу по конвейеру
тех-дизайн → граф задач → таск-планы → реализация → ревью, с циклами проверки
«А сделал — Б проверил — А поправил» (максимум три круга, дальше эскалация к
человеку) и остановкой ветки на открытых вопросах до ответа человека.
Независимые ветки при этом продолжают работу.

Название: методология [metaswarm](https://github.com/dsifry/metaswarm) плюс
durable-рантайм под ней — её состояние сейчас живёт в контексте LLM, а не в коде.

**Статус: тех-дизайн написан, production-кода ещё нет.** Фаза M0 закрыта:
реальные vendor CLI проверены, сохранены fixtures и fake CLI для будущих тестов.
Стек выбран, вопросы к требованиям закрыты, схема состояния и архитектура
спроектированы. Что решено —
[`docs/metaResearches/decision.md`](docs/metaResearches/decision.md); как это
устроено — [`docs/design/`](docs/design/).

Коротко: собственное узкое ядро на Python 3.12+ с SQLite для состояния, свои
адаптеры вендорских CLI, свой протокол разрешения findings и свой Telegram-мост.
Gas City, Conductor, Orca, bernstein и metaswarm — доноры кода и идей, не
зависимости рантайма.

## Что где лежит

| Путь | Что это |
|---|---|
| `docs/metaResearches/decision.md` | **Решение целиком: стек, границы v1, модель данных, протокол ревью, инварианты, приёмочные сценарии, порядок работ.** Начинать отсюда |
| `docs/design/` | **Тех-дизайн: архитектура, схема SQLite, контракты агентов, разбивка на задачи.** Отвечает на «как исполнимо» |
| `docs/requirements/initial.md` | Исходные требования к системе |
| `docs/requirements/open-questions.md` | Все вопросы к требованиям с вариантами, оценкой уверенности и ответами. Закрыты все |
| `docs/researches/` | Предварительные ресёрчи ландшафта, собранные веб-агентами по README, статьям и блогам — по файлу на модель. Исходный материал: документы расходятся между собой и местами с кодом |
| `docs/analysis/` | Проверка отдельных утверждений ресёрчей по коду, со ссылками на строки |
| `docs/metaResearches/` | Как пришли к решению: сводные разборы по моделям, `finalDecision.md` с обоснованиями и вердиктами, `planesExplained.md` — то же простым языком |
| `refs/` | Клоны анализируемых проектов. Только для чтения, в `.gitignore` |
| `refs/manifest.tsv` | Что тянем и зачем |
| `refs/pinned.tsv` | Коммиты, на которых сделаны выводы |
| `scripts/sync-refs.ps1` | Разложить `refs/` по манифесту |

Развернуть референсы:

```powershell
pwsh scripts/sync-refs.ps1            # всё
pwsh scripts/sync-refs.ps1 -Tier 0,1  # только ядро
```
