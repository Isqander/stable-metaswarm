## Что уже выяснилось

**Из 29 инвариантов `decision.md` §13 двенадцать держит база целиком**,
пять — совместно с кодом, двенадцать — код. Все оставшиеся за кодом оказались
утверждениями о полноте множества или о порядке операций; ни одного про отдельную
запись. Это разумная граница, и она была главным вопросом к схеме.

**Проектирование нашло пять пропусков в решении** — они перечислены в
`db-schema.md` §14. Один из них несущий: типов связи наблюдения с личностью
должно быть четыре, а не три, иначе период открытости severity вычислить нечем.
`decision.md` §6.3 поправлен.
